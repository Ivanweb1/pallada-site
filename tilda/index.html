Пульт переноса на Тильду

Для каждой страницы прототипа здесь собирается готовый код вайб-блока: разметка страницы, стили под неё и скрипт. Всё свёрнуто в один контейнер .pallada, поэтому код не задевает остальную страницу Тильды. Картинки остаются на GitHub Pages и подключаются по абсолютным адресам.

Как переносить

  1. В Тильде создайте страницу и добавьте вайб-блок (или T123 «HTML-код») во всю ширину.
  2. Нажмите здесь «Код блока» у нужной страницы и вставьте код в блок. Рядом кнопки для настроек страницы в Тильде: Название, Title, Описание, URL прототипа.
  3. Один раз на сайт: скопируйте «Общий CSS» и «Общий скрипт» из блока ниже и вставьте их в Настройки сайта → Дополнительно → HTML-код в HEAD. Без этого код страницы весит больше 100 КБ и Тильда его не сохранит.
  4. Шапку и подвал удобно вынести отдельными блоками и переиспользовать на всех страницах — снимите обе галочки и скопируйте их коды ниже.
  5. Формы. На страницах с формой (главная, контакты) добавьте обычный блок с формой Тильды и подключите ему приёмник данных. Код блока найдёт её сам, уберёт с глаз и будет отправлять заявки через неё: в приёмник уходят Имя, Телефон, E-mail, а также поля «Форма», «Страница» и «Детали» (комментарий и имя прикреплённого файла). Сам файл Тильда через такую форму не принимает.

Настройки кода

Ссылки: пустое поле — остаются как в прототипе (company.html). Введите префикс адресов Тильды — например /, и ссылки станут /company, главная — /.
CSS и скрипт по умолчанию вынесены в HEAD сайта: со стилями внутри блок весит 110–170 КБ, а Тильда не сохраняет вайб-блок тяжелее 100 КБ. Вес готового кода показан у каждой строки, красным — если не влезет.
